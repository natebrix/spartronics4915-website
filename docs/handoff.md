# Handing off the website each year

The site outlasts each class of students only if the web lead role and the
account access are passed on every spring, on purpose.

## The web lead role

Two students share it: one from business/marketing and one from programming.
Captains choose them each spring. Outgoing leads overlap with the new ones for
at least a month.

## End-of-season checklist (May)

- [ ] Choose next year's web leads. Outgoing leads walk them through making, reviewing and undoing a change (see [CONTRIBUTING.md](../CONTRIBUTING.md)).
- [ ] Update GitHub organization members and the teams named in `.github/CODEOWNERS`; remove graduated students.
- [ ] Review the account table below. Every account needs at least two mentors with access.
- [ ] Check the domain's renewal date and payment method.
- [ ] Update the Join page, the sponsor list, the countdown and the history timeline for next season.
- [ ] Merge pending dependency updates and confirm `npm run verify` passes.
- [ ] Read through `docs/` and fix anything out of date.
